# GIA – Digital Marketing Advisory

Website for GIA, a digital marketing advisory in Egypt. Arabic and English, with a proper right-to-left layout for Arabic.

Pages: home, about, 12 service pages, industries, work, insights, and contact. SEO basics are in place (hreflang, structured data, sitemap).

Built with Next.js, TypeScript and Tailwind CSS.

```
npm install
npm run dev
```
